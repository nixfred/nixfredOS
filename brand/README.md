# nixfred brand

Source of truth for the nixfred logo files. Redrawn as vector from the master lockup.

| File | Use |
|------|-----|
| `nixfred-logo.svg` | Full lockup (hexagon, `>_`, wordmark, Larry face). Transparent, for dark backgrounds. |
| `nixfred-logo-light.svg` | Same lockup with a dark wordmark and prompt, for light backgrounds. |
| `nixfred-icon.svg` / `nixfred-icon-light.svg` | Hexagon with `>_` only (dark / light backgrounds). |
| `nixfred-favicon.svg` | Icon on a dark rounded tile; this is what browsers show in the tab. |
| `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` | Raster favicons (16/32/48 ICO, 32 px PNG, 180 px opaque PNG). |
| `og.png`, `nixfred-og.svg` | 1200x630 social card. |

Rasterized with `rsvg-convert`; the redraw matches the master at PSNR 40.1 dB.
